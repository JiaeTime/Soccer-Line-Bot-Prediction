# Football LINE Bot ⚽

A LINE chatbot that provides daily football fixtures and match probability estimates for the **Big Five European football leagues**:

* 🇬🇧 Premier League
* 🇪🇸 La Liga
* 🇮🇹 Serie A
* 🇩🇪 Bundesliga
* 🇫🇷 Ligue 1

## Project Overview

The goal of this project is to build a personal football assistant through LINE.

The bot will retrieve the day's fixtures, display match information, and provide estimated probabilities for each match:

* Home win
* Draw
* Away win

For example:

```text
⚽ Today's Matches

🇬🇧 Premier League

Arsenal vs Newcastle
Kickoff: 20:00

Arsenal:   61%
Draw:      23%
Newcastle: 16%
```

The probabilities are generated by a prediction model based on football data and are intended as statistical estimates rather than guaranteed outcomes.

## Planned Features

### Fixtures

* Retrieve fixtures from the five leagues
* Show today's matches
* Show tomorrow's matches
* Display kickoff times in Thailand time
* Group matches by league

### Match Predictions

The prediction system will initially use a simple statistical model and gradually become more sophisticated.

Potential factors include:

* Team strength
* Home advantage
* Recent form
* Goals scored
* Goals conceded
* Historical performance
* Other available match statistics

### LINE Commands

Planned commands include:

```text
/today
/tomorrow
/prem
/laliga
/seriea
/bundesliga
/ligue1
/predict
```
